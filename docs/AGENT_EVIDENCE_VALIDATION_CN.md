## 真实问题与验证方法

冻结 `4cf8f226` 的 13 份项目文档，按章节形成 60 个逻辑文档，再由两个模型 tokenizer
共同约束切成 95 个检索片段。42 条查询均为固定公开 GitHub issue 快照中的真实标题；
正文、评论以及问题标题没有进入检索库。完整文档、查询、来源、标注和 hash 已放入
`benchmarks/agent_evidence`，可直接离线重现。

9 条查询有人工相关文档路径标签，其余 33 条只用于性能与协议输入覆盖。
标签是“相关说明文档”，不是历史 bug 已解决的证据。没有生成式问题扩充，
没有接入外部 LLM，因此不声称智能体端到端任务成功率。

四端点分别执行 22 项 CPU/协议回归，均无 skip；再执行实际模型适配器、同设备 PyTorch FP32 抽检、
168 次检索质量运行、原文引用校验、索引更新/撤回、超长查询提前拒绝、权重地址/上传字节不变、
真实 GPU/MLU/NPU MCP 子进程的初始化/读取/错误输入/3 并发请求串行模型访问。
数值抽检覆盖一个真实 query 的 embedding 和两个真实 query/passage 的 logit，
逐元素要求 atol=1e-4、rtol=1e-3；基础引擎的历史覆盖不冒充本轮重新执行。

## 质量结果与默认行为

四端点的下表结果相同；每次都对返回引用核对原文 span 和来源 revision。
这是小规模、有主观路径标注的试用集，不是有统计把握的通用检索结论。

| 方式 | 相关文档 Hit@5 | MRR@5 |
|---|---:|---:|
| BM25 | 77.78% | 0.4074 |
| 向量 | 100.00% | 0.6852 |
| RRF 混合 | 88.89% | 0.5185 |
| 混合 + 通用 reranker | 66.67% | 0.3093 |

通用 reranker 在项目术语和该标注规则下产生退化，因此没有默认启用。
CLI、Python 服务和 MCP 都默认混合召回、不精排；`--rerank` 明确选择精排。
保留 `--mode vector`，但不依据 9 个标签把一种检索方式包装成普遍最优。
后续应增加真实用户查询和分级相关性标注，再做领域模型选择/微调及召回参数选择。

## 共享负载性能

每端点一个驻留模型实例，三轮轮换 4 种方式；每组预热 5 次、测量 84 次，
42 条查询每轮各执行两次。每方式汇总 252 个原始样本，表中为合并样本的 p50/p95（ms）。
每端点共 1,008 个正式计时请求，四端点共 4,032 个。
这是本应用的试用测量，不替代 M1 的 20/200 全引擎基准规范。

统一 recall_k=24、最多返回 5 条、上下文预算 2048 reranker tokenizer token。
计时同步设备，包含过滤、CPU 检索、模型提交/执行、数据传输、拼装与预算计数；
不包含 MCP stdio 传输、LLM 推理、模型冷加载和建库。
使用 normal 执行模式，没有把图重放或独占设备作为条件。
未停止其他用户进程；原始证据包含设备利用率、空闲内存和外部进程采样。
A100 使用已有的进程级 THP 关闭策略，未修改全局 THP 设置。

| 平台 | BM25 基线 | 默认混合，无推理缓存 | 混合+精排，无推理缓存 | 混合+精排，精确重复缓存 |
|---|---:|---:|---:|---:|
| L20 | 1.09 / 2.17 | 7.63 / 8.82 | 90.35 / 96.57 | 3.16 / 4.25 |
| A100 | 1.68 / 3.46 | 12.46 / 14.51 | 145.24 / 154.59 | 4.71 / 6.48 |
| MLU590 | 2.06 / 4.24 | 16.99 / 19.22 | 133.76 / 138.18 | 5.66 / 7.82 |
| 昇腾 910B2C | 1.60 / 3.41 | 7.83 / 9.66 | 69.24 / 73.32 | 3.77 / 5.57 |

最后一列先预热全部 42 条精确查询及其候选 query/passage 分数，命中后仍重新读取和过滤当前索引、
生成引用；三轮都断言 embedding/reranker 执行计数没有增加，输出和无缓存精排一致。
它展示完全重复请求的上界收益，不是任意新查询加速，也不是最终回答缓存。
默认混合列与精排列采用不同排序，不能把二者延迟差当成同等质量的算子优化。
词法基线与其他方式使用相同预算计数器，验证进程中两个模型均已驻留，不是独立 CPU 部署内存对照。

| 平台 | 模型适配器加载 s | 95 片段建库 s | MCP 子进程初始化 s |
|---|---:|---:|---:|
| L20 | 27.75 | 0.31 | 29.53 |
| A100 | 28.52 | 0.48 | 30.80 |
| MLU590 | 44.59 | 0.89 | 54.93 |
| 昇腾 910B2C | 37.47 | 2.45 | 45.07 |

加载包括模型包校验和依赖/运行库初始化，应使用驻留服务。机器可读摘要另有本进程 RSS、
设备内存和 ATen allocated/reserved 的最大采样值；同一验证进程先执行过 PyTorch 对照，
保留内存可能受其影响，不能当作最小服务占用或正式峰值/泄漏结论。
本轮没有在受控负载下做跨卡速度排名，也没有 ORT 应用级对照。
